# Pfennig

Lokale macOS-Buchhaltung für deutsche Freiberufler mit EÜR und Ist-Versteuerung. Dateien ablegen, ein KI-Agent bucht, der Nutzer prüft, UStVA und EÜR werden exportiert.

Die Spezifikation steht in `docs/specs/pfennig-neu.md`, der aktuelle Stand in `docs/status.md`. Bauen mit `scripts/build.sh`, Tests mit `scripts/test.sh`.
