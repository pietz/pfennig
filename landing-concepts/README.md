Current working draft: [daft.html](daft.html), built from the agreed copy in [copy.md](copy.md) with semantic HTML and unchanged DaftCSS, without custom CSS or JavaScript. The copy was worked out section by section before the page was rebuilt (2026-09-21). Screenshots remain plain placeholders. Framework source notes are in [daft-assets](daft-assets/).

Pfennig will be offered free, without open-source positioning. The page shows two ways to run the document reading: a subscription from version 1.0 on, listed first, and the user's own OpenAI key billed by OpenAI. Repository visibility and licensing have not changed. Final download hosting and publication remain undecided; the draft still links to the existing GitHub release. Earlier concepts are exploratory, not fact-checked publication copy.
