Current working draft: [daft.html](daft.html), rebuilt directly with semantic HTML and unchanged DaftCSS, without custom CSS or JavaScript. Uses the owner's chosen headline “Buchhaltung ohne Buchhaltung.” and personal benefit-led copy. Screenshot remains a plain placeholder. Framework source notes are in [daft-assets](daft-assets/). This replaces the rejected custom-styled Luna DaftCSS draft.

The owner prefers Gemini's centered layout, with monochrome styling and fewer cards for the next round. Pfennig will be offered free, without open-source positioning; users supply their own OpenAI key and pay usage separately. The current draft reflects this decision. Repository visibility and licensing have not changed. Final download hosting and publication remain undecided; the draft still links to the existing GitHub release. Earlier concepts are exploratory, not fact-checked publication copy.
