# Vendored Daft CSS

`daft.min.css` is Daft CSS v1, vendored from https://github.com/pietz/daftcss.
The framework belongs to the project owner. A standalone license notice could not be retrieved from the upstream repository or package endpoint during this exploration; verify redistribution terms before publishing this vendored copy.

`preview.svg` is a plain gray screenshot placeholder created for this page.

The three inline card icons are Lucide `file-input`, `calculator` and `clipboard-check`, copied from `lucide-static@1.47.0` on unpkg.com. Their paths are unchanged; dimensions are 20px and the decorative SVGs are hidden from assistive technology. License: [lucide-LICENSE](lucide-LICENSE).

`pfennig.png` is the existing app brand mark copied from `App/Resources/Assets.xcassets/PfennigMark.imageset/`.

The inline Apple logo path in `daft.html` comes from Simple Icons (`https://cdn.simpleicons.org/apple`), with fill set to `currentColor`. Simple Icons artwork is CC0; brand trademarks remain with their owners.
